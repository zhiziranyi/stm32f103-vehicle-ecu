# STM32F103 车辆 ECU 验证清单

| 场景 | 操作 | 通过判据 |
|---|---|---|
| 构建 | `pio run -e genericSTM32F103C8` | 固件编译完成。 |
| CAN 上报 | 使用 CAN 分析仪监听 | 能周期性看到 `0x100` 与 `0x200` 状态帧。 |
| 模式命令 | 发送 `0x300` 并改变 mode 字节 | 目标转速在 300/600/1000 三档间切换。 |
| PWM | 低压台架示波器观察 | PA6/PA7/PB0 输出按预期变化。 |
| 传感器 | 连接 AS5600 | I2C 不阻塞主循环，角度读取稳定。 |

所有电机测试先做无负载、低压与限流验证；未实现的保护功能不应作为安全保障。
