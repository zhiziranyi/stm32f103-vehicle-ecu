# STM32F103 车辆 ECU 交接文档

更新时间：2026-08-25  
配套网关：`stm32f407-vehicle-dashboard`

## 1. 系统职责

该 ECU 节点使用 STM32F103C8，通过 CAN 500 kbps 模拟/输出 BMS 和电机状态，并接收 F407 网关的整车状态帧来切换目标电机转速。电机部分使用开环 SVPWM 演示链路，不能替代具有电流采样、过流保护和故障诊断的量产逆变器控制器。

## 2. 接线

| STM32F103 | 外设 | 用途 |
|---|---|---|
| PB8 / PB9 | CAN 收发器 RX / TX | CAN1，500 kbps；总线两端各 120 Ω 终端 |
| PA6 / PA7 / PB0 | 三相驱动器 PWM 输入 | Mini 三相驱动 PWM |
| PA4 / PA5 | 驱动 `EN` / `nSLEEP` | 使能与休眠控制 |
| PB6 / PB7 | AS5600 SDA / SCL | I2C 角度传感器 |

CAN 收发器、F103 与 F407 必须共地；电机驱动功率电源和逻辑电源须按驱动板要求隔离/共地，禁止从开发板 GPIO 供给电机电流。

## 3. CAN 协议边界

| 标准 ID | 含义 |
|---:|---|
| `0x100` | BMS 电池状态 |
| `0x200` | 电机控制器状态 |
| `0x300` | 整车状态；第 2 字节用于驾驶模式 |
| `0x301` | 整车控制命令 |
| `0x400` / `0x401` | BCM 状态/控制 |
| `0x500` | 故障码 |

## 4. 开发与安全

```powershell
pio run -e genericSTM32F103C8
```

项目当前 `platformio.ini` 使用 ST-Link 上传。接入真实电机前，先用示波器检查三路 PWM 相位与占空比；只在低压、可限流电源下做台架实验。任何涉及实车、高压电池或真实牵引电机的测试均不在本项目的安全边界内。
